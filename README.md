# SL TEC – Total Technical Solution (Maldives)

A fully operational, high-performance website built with **React 18**, **TypeScript**, **Tailwind CSS**, and **Lucide React**, designed to match the generator sales, repair, and maintenance operations structure across all Maldives islands and resorts.

---

## ⚡ Key Features & Structure

- **Top Announcement Bar**: Emergency hotline, working hours, 28+ years experience badge, and island coverage status.
- **Header & Navigation**: Sticky blur navigation with mobile hamburger drawer, hotline button (`7370267`), and quick quote booking modal trigger.
- **Hero Section**: Dark technical background with high-contrast typography: *"Reliable Generator Sales, Repair & Maintenance in Maldives"*, action buttons, and 4 key metric counters (28+ Years, 200+ Islands, 500+ Projects, 24/7 Hotline).
- **Floating Emergency Breakdown Banner**: Immediate contact widget connecting directly to phone call or WhatsApp hotline.
- **After-Sales Services We Offer (6 Core Services)**:
  - Generator Repair & Overhaul
  - Marine & Ship Engine Service
  - Control Panels & Automation (DSE/ComAp/ATS)
  - Installation & Commissioning
  - Kitchen Hood & Commercial Equipment
  - Load Calculation & Power Audits
- **Your Power, Our Priority (Why Us)**: 6 key technical value propositions, technician visual card with 28+ years experience badge, and manufacturer logo strip (Cummins, Perkins, CAT, Yanmar, Volvo Penta, Kohler, Stamford, DSE).
- **Generator Products & Equipment**: 4 core product categories with specifications, power ratings, and direct inquiry modals.
- **Generator Projects Delivered Islandwide**: Interactive filterable project gallery with case study modals (Resorts, Marine, Industrial, Emergency).
- **What Our Clients Say**: Real client reviews from resort directors and marine fleet managers.
- **Generator Maintenance Tips & Expert Guides**: Technical articles with advice for tropical marine environments.
- **Orange Gradient CTA Banner**: High-impact direct hotline and consultation request.
- **Contact & Atoll Selector Form**: Real-time validated booking form with atolls dropdown and feedback toast notifications.
- **Footer**: 4-column layout matching industry standards with emergency contact details and hashtags.
- **Interactive Modals**:
  - Quote & Service Request Modal
  - Service Detail Modal
  - Product Specifications Modal
  - Project Case Study Modal
  - Article Guide Reader Modal
  - Toast Notification System
- **Floating Actions**: Pulsing green WhatsApp direct button and smooth Back-to-Top button.

## 🚀 Running the Project

### Option A: Modern React + TypeScript Development (Recommended)

1. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:3000`.

2. **Build for Production**:
   ```bash
   npm run build
   ```
   The compiled, optimized files will be generated in `dist/`.

3. **Preview Production Build**:
   ```bash
   npm run preview
   ```

---

### Option B: Direct Standalone File (No Node/Build Required)

You can also directly double-click or open `standalone.html` in any web browser without needing any command line or server setup.
